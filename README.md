# La Bonita Brunch website

A Markdown mirror of [labonitabrunch.net](https://labonitabrunch.net/), the website for La Bonita Brunch, a family-owned Mexican breakfast, brunch and lunch food truck in Redmond, Oregon.

This repo is a copy for reference and backup. The live site runs on Squarespace, so changing a file here does not change the website.

- **Address:** 958 NW 6th St, Redmond, OR 97756 (just north of Brightside Thrift)
- **Phone:** [(541) 678-4991](tel:+15416784991)
- **Hours:** Monday–Friday 7:00 am–2:30 pm · Saturday 7:00 am–2:00 pm · Sunday closed
- **Order online for pickup:** [Clover](https://la-bonita-brunch-redmond.cloveronline.com/menu/all)
- **Social:** [Instagram](https://www.instagram.com/labonita_brunch/) · [Facebook](https://www.facebook.com/p/La-Bonita-Brunch-61579161419085/) · [Yelp](https://www.yelp.com/biz/la-bonita-brunch-redmond)
