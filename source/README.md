# Site source

The code behind labonitabrunch.net and where each piece lives in Squarespace. To change the live site, edit it in Squarespace, then update the copy here.

| File | What it is | Where it lives in Squarespace |
|---|---|---|
| [homepage-code-block.html](homepage-code-block.html) | The whole homepage: layout, styles, menu, photos, FAQ, hours and search data | Pages → Home → Edit → the code block on the page |
| [custom.css](custom.css) | Styles for the blog pages: dark theme, logo, fonts, photos, footer | Pages → Website Tools → Custom CSS |
| [footer-injection.html](footer-injection.html) | The blog footer (address, phone, hours, links) and the header Order button | Pages → Website Tools → Code Injection → Footer |
| [header-injection.html](header-injection.html) | Google and Bing site verification tags | Pages → Website Tools → Code Injection → Header |
| [../llms.txt](../llms.txt) | Summary for AI tools | SEO / AI Visibility → SEO Settings → LLMS.txt |
